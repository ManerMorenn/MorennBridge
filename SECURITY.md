# Security

Please report vulnerabilities by email to tristan.allaire@manermorenn.com rather than in a public issue. Include the
Blender version and steps to reproduce. You can expect a first answer within a week.

The latest release is the only supported version.

Unreal Link uses Unreal's Python remote execution, which runs code inside the editor by design. MorennBridge only
sends its own scripts, from its own install folder, to an editor you selected. Reports about the remote execution
protocol itself belong to Epic Games.
